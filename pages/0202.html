工程结构 ​

认识 chattrade-workspace 三个工程各自放什么。

工作区布局 ​

chattrade-workspace 当前包含：

目录职责
chattrade.org文档站源码与构建产物配置
chattrade-web桌面端 Vue 应用：src/views、src/api、src/config
chattrade-mobile手机端 Vue 应用：src/views、src/api、Capacitor 配置

桌面端关键目录 ​

路径含义
src/views/*业务页面（AI、策略、回测、券商、计费等）
src/api/*对后端 /api/* 的封装
src/config/router.config.js路由与菜单
deploy/Nginx / Caddy 与容器反代模板

手机端关键目录 ​

路径含义
src/views/*AI、交易、行情、个人中心等页面
src/router路由表
android/、capacitor.config.json原生打包相关

文档站的 docs/NN.标题 目录由 npm run gen 生成侧栏与 URL，不要手改 navigation.json。
