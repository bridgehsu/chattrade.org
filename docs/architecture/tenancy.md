# 多商户架构

<div class="doc-lead">商户上下文贯穿配置、账户、交易和后台权限。</div>

## 已观察到的结构

工程存在商户服务与商户后台，交易对、账户及部分业务对象包含商户维度。文档据此把商户作为重要业务上下文，但不宣称所有服务已完成完整租户隔离审计。

## 隔离维度

商户可影响应用配置、交易产品、费用参数、管理权限和报表口径。查询、更新、缓存键和消息处理都应明确所属商户，不能只在页面入口过滤。

## 配置生效流程

<Flow :steps='["确定商户与作用范围","提交配置变更","校验与审核","刷新目标服务配置","验证生效与记录审计"]' />

配置变更应说明影响新订单还是存量订单。结算关键参数应保留可追溯版本，防止后台修改后无法解释历史收益。
