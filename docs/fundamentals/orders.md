# 委托、撮合与成交

<div class="doc-lead">理解订单为何可能成交多次，以及撤单究竟撤销什么。</div>

## 三个对象

委托表达交易意图，例如以不高于 60,000 的价格买入 0.01 BTC。撮合负责寻找符合条件的对手订单。成交记录描述实际发生的一次交换。

一个委托可以没有成交，也可以产生多笔成交。撤单只终止未成交部分，已经完成的成交保留。

## 状态与数量

原始数量 = 累计成交数量 + 剩余数量。对于已撤销订单，剩余数量不再参与交易，但历史成交仍需要结算。

## 盘口、行情与 K 线

盘口描述当前挂单，最新成交描述已经发生的交易，K 线是某个时间区间内成交价格和成交量的聚合。三者更新时间和数据含义不同。
