# 用户与账户体系

<div class="doc-lead">区分用户身份、资产账户和后台角色。</div>

## 业务对象

用户身份回答“是谁”，资产账户回答“在哪个业务域拥有多少权益”，后台角色回答“可以管理什么”。一个用户可能关联多个业务账户，但不应由此获得后台权限。

工程中用户服务、账户服务、用户关系服务和商户管理服务分别承载相关职责。

## 用户关系

邀请关系用于运营归属与奖励计算，不等于资产所有权，也不应自动带来查看被邀请人隐私或操作其资产的权限。关系变更、商户归属和奖励归属应分别说明。
