# 部署架构

<div class="doc-lead">客户端静态资源与后端 API 的推荐部署关系。</div>

## 推荐拓扑

<Flow :steps='["构建 web / mobile 静态资源","Nginx 托管页面","/api 反代到后端","配置 HTTPS 与域名","验证登录与只读业务"]' />

| 组件 | 配置要点 |
| --- | --- |
| chattrade-web 容器 | `BACKEND_URL`，模板见 `deploy/nginx-docker.conf.template` |
| chattrade-mobile 容器 | 同样需要 `BACKEND_URL` 或等价反代 |
| chattrade.org | 纯静态文档，无业务 API 依赖 |

## 发布检查

记录镜像或构建版本、后端地址、是否强制 HTTPS、Cookie 域是否匹配。前端滚动发布时，旧页面可能短暂打到新 API，注意兼容。

## 文档站

`chattrade.org` 使用 `npm run build` 产出 `dist/`，可按仓库 README 部署到静态托管或 GitHub Pages，域名 `chattrade.org`。
