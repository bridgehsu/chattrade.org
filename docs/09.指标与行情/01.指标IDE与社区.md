# 指标 IDE 与社区

<div class="doc-lead">指标用于图表可视化；社区用于发现与复用指标。</div>

## 指标 IDE

`/indicator-ide` 用于编写图表指标（可视化），与 Strategy IDE 的可执行策略脚本不同。指标代码服务画线与标记，不应被描述为自动下单逻辑。

## 指标社区

`/indicator-community`（桌面）与手机 `/market` 提供浏览、详情与已购内容。购买或安装指标只影响图表能力，不自动授权策略实盘资金。

## 边界

把“指标信号”当成交易指令前，必须经过策略/执行模块与账户风控。图表刷新失败时，先检查行情源与登录态，再判断指标脚本本身是否报错。
