# 行情与资产池

<div class="doc-lead">行情展示与 Universe 管理为研究与回测提供标的集合。</div>

## 行情

客户端通过 market 相关 API 拉取行情与模块配置。行情是展示与研究输入；成交事实仍以交易/券商回执为准。

## Universe

`/universe-manager`（桌面，可隐藏入口）用于管理标的池，供回测与研究复用。资产池变更不会自动修改已运行策略的绑定标的，除非执行配置显式引用该池。

## 手机图表

`/indicators/chart` 是移动端主要看盘与快捷交易入口。网络抖动下应允许手动刷新，避免把过期报价当作成交依据。
