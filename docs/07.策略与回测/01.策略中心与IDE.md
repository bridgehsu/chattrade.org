# 策略中心与 IDE

<div class="doc-lead">策略中心管理运行中的策略，IDE 负责编写与校验脚本。</div>

## 职责拆分

| 页面 | 职责 |
| --- | --- |
| 策略中心 `/strategy-center` | 查看、启停、跟踪策略与执行状态 |
| Strategy IDE `/strategy-ide` | 编写、生成、校验策略代码 |
| 手机 `/trading` | 列表、详情、创建机器人/策略的轻量入口 |

## 核心对象

策略描述交易决策逻辑；执行器/机器人负责把信号变成订单；账户与券商连接决定真实成交通道。IDE 里的可运行草稿在未部署前不应计入实盘绩效。

## API 分组

客户端封装可见 `/api/strategies`、脚本源、AI 生成、执行器模板与预览等接口。创建、更新、发布脚本源应分步确认，避免未校验代码直接进入实盘执行。
