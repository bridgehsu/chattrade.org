# 回测中心

<div class="doc-lead">用历史数据检验策略规则，而不是预测未来收益。</div>

## 流程

<Flow :steps='["选择策略或脚本","配置标的与区间","提交回测","查看曲线与成交明细","决定是否进入实盘"]' />

桌面端入口为 `/backtest-center`。相关 API 包括 `/api/backtest/run`、历史查询与因子研究等。回测可能持续数分钟，客户端使用长超时；超时后先查历史记录，避免重复提交同一任务。

## 阅读结果时注意

1. 收益曲线依赖样本区间与费用假设。
2. 滑点、手续费与成交规则需与实盘环境对照。
3. 因子研究报告是研究产物，不自动变成正在运行的策略。

回测通过只说明“历史样本上可解释”，不构成实盘承诺。
