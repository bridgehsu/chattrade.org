# 执行器与机器人

<div class="doc-lead">把策略信号落到自动执行，并管理启停与剩余敞口。</div>

## 执行链路

<Flow :steps='["确认策略参数","绑定账户与权限","启动执行","跟踪订单与持仓","停止并处理剩余敞口"]' />

桌面端通过策略/执行器相关 API 创建与预览执行配置；手机端可在交易页创建机器人或策略并查看详情。停止运行不等于已撤销全部挂单或平掉仓位，完成条件要写清。

## 风险点

| 风险 | 说明 |
| --- | --- |
| 信号重复 | 需要去重或幂等，防止重复下单 |
| 外部限频 | 交易所/券商限流会影响同实例其他任务 |
| 部分成交 | 执行状态与目标仓位可能不一致，需可查询 |

执行日志、通知与未读数用于运维观察，不能替代订单与持仓查询。
