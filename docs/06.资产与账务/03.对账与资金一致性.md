# 对账与资金一致性

<div class="doc-lead">通过事实核对定位差异，而不是直接修改余额。</div>

## 对账层次

| 层次 | 核对内容 |
| --- | --- |
| 订单对账 | 委托累计成交数量与成交明细是否一致 |
| 账户对账 | 余额变化是否能由流水解释 |
| 业务对账 | 成交、提现、划转是否完成对应入账 |
| 链上对账 | 链上转账、钱包记录与内部充提记录是否一致 |

## 差异处理

先定位账户、币种和业务编号，再核查原始事实、重复处理记录和未完成任务。修复应保留原因、审核和新的可追溯记录，避免覆盖历史事实。

## 一致性目标

幂等键、条件更新、业务唯一约束、失败重试和补偿是常见设计手段。当前文档将其作为检查目标，不代表所有服务已通过完整的一致性验证。
