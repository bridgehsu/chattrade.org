# 本地开发与构建

<div class="doc-lead">说明 chattrade-mobile 的安装、开发与构建命令。</div>

## 开发

```sh
npm install
npm run dev
```

默认 `http://localhost:5173`。可按需设置：

```sh
VITE_DEV_API_TARGET=http://127.0.0.1:5000 npm run dev
```

## 构建

按工程 README 执行生产构建（通常为 `npm run build`），再将 `dist` 交给静态托管或 Capacitor sync。

## 验证

1. 登录页可打开。
2. 登录后 AI / 交易 Tab 能打到 `/api`。
3. 断网或错误后端时，错误提示可读，不会白屏卡死。

原生调试需在对应 IDE 中运行，文档不代替平台官方签名与上架流程说明。
