# H5 与原生打包

<div class="doc-lead">同一套 Vue 3 代码可发布为 H5 或 Capacitor 应用。</div>

## 发布形态

| 形态 | 说明 |
| --- | --- |
| H5 / Docker 静态站 | 构建产物由 Nginx 托管，`/api/` 反代后端 |
| Android | Capacitor + Android Studio |
| iOS | 需 macOS 与 Xcode |

`capacitor.config.json` 中的 `appId` / `appName` 决定原生应用标识；发布前按 ChatTrade 品牌与包名规范核对。

## 后端连接

容器内通过 `BACKEND_URL` 注入反代目标。局域网真机访问 H5 时，使用电脑局域网 IP，并保证手机能访问该主机端口。

## 注意点

原生壳内的 WebView 仍走相对路径 `/api`。深链接、推送与安全存储属于 Capacitor 插件能力，启用前确认对应权限与商店合规要求。
