# 产品能力与路由

<div class="doc-lead">认识 chattrade-mobile 的主要场景与路由。</div>

## 定位

手机端服务随身场景：查看 AI 分析、管理策略/机器人、看行情图表、闪电交易、维护个人设置与交易所相关配置。它不是另一套后端，而是同一 API 上的移动界面。

## 主要路由

| 路由 | 能力 |
| --- | --- |
| `/ai` | AI Hub |
| `/ai-analysis` | AI 分析与历史 |
| `/trading` | 策略 / 机器人列表与详情 |
| `/trading/create*` | 创建机器人或策略 |
| `/market` | 指标市场与购买 |
| `/indicators/chart` | 图表；可带交易入口 |
| `/profile` | 个人中心、通知、语言、关于 |

`/quick-trade` 会重定向到图表页并打开交易相关查询参数，避免维护重复页面。

## 与桌面端差异

手机端交互更轻：复杂 IDE、完整运营后台仍以 `chattrade-web` 为主。能力是否可用取决于后端与账号权限，路由存在不等于功能已开通。
