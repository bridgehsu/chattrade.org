# 核心设计

<div class="doc-lead">把订单、持仓、保证金和风险状态分开建模。</div>

## 账户与持仓 {#position}

订单表达待执行意图，持仓表达已成交敞口。持仓通常需要方向、数量、开仓均价、可平数量和相关保证金。撤销未成交的开仓订单不等于平掉已经建立的持仓。

## 订单状态 {#orders}

订单状态反映受理、成交和终止结果；持仓状态反映有效敞口和关闭过程。二者不能共用一套状态含义，强平过程也需要关联具体持仓和清算记录。

## 保证金与盈亏 {#pnl}

线性合约的简化多仓浮盈 = 数量 ×（参考价格 − 开仓均价）；空仓方向相反。合约乘数、结算币、手续费和资金费会影响实际权益。本公式仅用于说明方向关系。

## 风险与强平 {#risk}

风险计算需要稳定的价格与资产口径。权益低于对应维持要求时触发怎样的处理，应由产品规则和风险引擎决定；不能仅用“亏完初始保证金”作为所有产品的强平条件。
