# 本地开发与构建

<div class="doc-lead">说明 chattrade-web 的安装、开发代理与构建方式。</div>

## 开发

```sh
corepack enable
pnpm install
pnpm run serve
```

浏览器打开 `http://localhost:8000`。代理目标：

```sh
VITE_DEV_PROXY_TARGET=http://127.0.0.1:5000 pnpm run serve
```

请使用仓库内 `pnpm-lock.yaml`，不要提交 `package-lock.json`。

## 构建

```sh
pnpm run build
```

产物为静态资源，可由 Nginx 托管。容器场景下用 `deploy/nginx-docker.conf.template` 将 `/api/` 反代到 `BACKEND_URL`。

## 校验建议

| 命令 | 用途 |
| --- | --- |
| `pnpm run lint` | ESLint |
| `pnpm run test:unit` | 单元测试 |

构建前确认 `APP_VERSION` / Git tag 注入符合发布约定。
