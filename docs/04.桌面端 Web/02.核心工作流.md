# 核心工作流

<div class="doc-lead">把研究、策略、回测与执行串成桌面端主路径。</div>

## 研究到执行

<Flow :steps='["AI 资产分析","形成策略想法","Strategy IDE 编写","回测验证","策略中心启动执行","券商/交易所成交"]' />

每一步都可能停在草稿态。回测通过不自动等于实盘运行；启动执行前需确认账户、凭证环境（模拟/实盘）与风控参数。

## API 线索

桌面端 `src/api` 中可见：

| 模块 | 典型前缀 |
| --- | --- |
| 策略 | `/api/strategies`、`/api/strategy-assets` |
| 回测 | `/api/backtest/*` |
| 闪电交易 | `/api/quick-trade/*` |
| 券商 | `/api/ibkr/*`、`/api/alpaca/*` |
| 鉴权 | `/api/auth/*` |

具体字段以联调环境响应为准，文档只固定分组与职责。

## 与手机端关系

同一用户在手机上看到的策略与机器人，应来自同一后端。桌面端功能更全；手机端侧重查看与轻量操作，见[手机端产品能力](/pages/0501)。
