# 产品界面与路由

<div class="doc-lead">认识 chattrade-web 的主要页面与菜单结构。</div>

## 默认入口

登录后默认进入 **AI 资产分析**（`/ai-asset-analysis`）。完整菜单由 `src/config/router.config.js` 定义，并按权限过滤。

## 主要路由

| 路由 | 能力 |
| --- | --- |
| `/ai-asset-analysis` | AI 资产分析与研究工作台 |
| `/strategy-center` | 策略中心 / 统一交易工作区 |
| `/strategy-ide` | 策略代码编辑 |
| `/backtest-center` | 回测中心 |
| `/indicator-ide` | 指标编辑与图表 |
| `/indicator-community` | 指标社区市场 |
| `/broker-accounts` | 券商账户连接 |
| `/billing` | 计费与会员 |
| `/profile` | 个人中心 |
| `/user-manage` 等 | 管理类页面（需 admin 权限） |

## 权限

`meta.permission` 控制菜单可见性。没有权限的路由不应只靠隐藏菜单保护，服务端仍需鉴权。详情页与创建页的关系以路由表为准，遗留重定向（如 `/portfolio` → 策略中心）用于兼容旧书签。
