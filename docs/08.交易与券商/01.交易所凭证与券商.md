# 交易所凭证与券商

<div class="doc-lead">管理 API Key 与 IBKR / Alpaca 等券商连接。</div>

## 能力范围

ChatTrade 通过绑定外部交易通道下单，而不是在本工作区实现独立撮合引擎。桌面端 `/broker-accounts` 与凭证相关组件用于连接、断开、查看账户与持仓。

## 券商 API 形态

客户端将 IBKR、Alpaca 等封装为统一调用形状，例如 status / connect / disconnect / account / positions / orders / placeOrder / quote。多租户隔离由服务端会话注册表处理，前端不传用户 id 覆盖身份。

## 安全要求

1. 密钥只提交给后端安全存储，不在日志或前端持久化明文。
2. 区分模拟与实盘环境，防止误对实盘下单。
3. 断开连接后，客户端应刷新状态，避免展示过期持仓。
