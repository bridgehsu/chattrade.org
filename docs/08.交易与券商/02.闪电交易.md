# 闪电交易

<div class="doc-lead">在图表或交易面板上快速下单、查余额与平仓。</div>

## 接口分组

桌面端 `src/api/quick-trade.js` 可见：

| 动作 | 路径语义 |
| --- | --- |
| 下单 | `/api/quick-trade/place-order` |
| 余额 | `/api/quick-trade/balance` |
| 持仓 | `/api/quick-trade/position` |
| 历史 | `/api/quick-trade/history` |
| 平仓 | 对应 close 接口 |

手机端通过图表页交易入口进入类似能力，路由上可能重定向到 `/indicators/chart?trade=1`。

## 使用原则

闪电交易强调速度，更要校验：交易对、方向、数量、环境（模拟/实盘）与可用余额。下单超时后先查历史/订单状态，禁止连点造成重复委托。
