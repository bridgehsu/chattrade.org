# 系统架构

<div class="doc-lead">现货链由委托、撮合、账户和行情共同完成。</div>

## 模块划分与职责 {#modules}

| 模块 | 主要职责 |
| --- | --- |
| coinex-entrust | 委托相关业务与查询 |
| coinex-match | 订单簿、撮合事件及相关账户运行态处理 |
| coinex-account | 业务账户与账务相关服务 |
| coinex-market | 行情相关处理 |
| 用户与商户服务 | 身份、交易产品和商户上下文 |

## 工程事实

现货撮合实现可见红黑树订单簿、买卖价格队列、Disruptor 事件处理和初始化撮合事件；委托类型枚举包含限价和市价，委托状态包含未成交、部分成交、完全成交与已撤销。
