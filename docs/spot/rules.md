# 交易规则

<div class="doc-lead">先确定订单是否合法，再判断能否成交。</div>

## 币种与交易对 {#pairs}

每个交易对需要定义基础币、计价币、交易状态与商户范围。只允许充值的币种不一定已开放交易，存在交易对记录也不代表处于可交易状态。

## 订单类型 {#types}

已检查的枚举包含限价单与市价单。限价买单约束最高买入价，限价卖单约束最低卖出价。市价单按可成交流动性执行，不承诺固定价格；买入以金额还是数量提交，应以实际版本规则为准。

## 精度、限额与手续费 {#limits}

价格精度、数量精度、最小数量和最小金额是不同约束。金额计算应使用明确的十进制精度与舍入规则，显示位数不能替代结算精度。

手续费需要说明费率来源、收取币种、收取时机和舍入方式。本文示例使用假设费率，实际费率由交易产品与商户配置决定。
