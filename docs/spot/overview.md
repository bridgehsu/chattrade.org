# 业务概述

<div class="doc-lead">现货交易以基础币与计价币的交换为核心。</div>

## 现货交易基础 {#basics}

在 BTC/USDT 交易对中，买方支付 USDT 获得 BTC，卖方支付 BTC 获得 USDT。系统需要确保订单符合规则、被占用的资金不能重复使用、成交后双方资产正确变化。

现货不是“订单价格变动后直接计算收益”的游戏，资产交换是它与周期结果类产品的重要区别。

## 交易界面与核心术语 {#interface}

| 界面区域 | 业务含义 |
| --- | --- |
| 交易对 | 说明交换的两种资产 |
| 盘口 | 展示当前买卖挂单的价格和数量 |
| 下单区域 | 表达方向、类型、价格或数量 |
| 当前委托 | 仍有未完成部分的订单 |
| 成交记录 | 实际成交的价格、数量和时间 |
| K 线 | 某一时间区间内行情的聚合 |
