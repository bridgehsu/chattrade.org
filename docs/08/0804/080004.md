# 核心交易流程

<div class="doc-lead">以权威周期和确定的价格依据完成一次结算。</div>

## 完整交易流程 {#complete}

<Flow :steps='["选择产品与周期","验证购买窗口","处理资金并建立订单","等待周期结束","确定结果与收益","入账并完成结算"]' />

## 下单与资金处理 {#place}

下单时记录用户选择、金额、周期、产品规则及收益口径。资金处理失败不应留下可参与收益结算的有效订单。响应超时应以订单编号核查受理结果。

## 到期与结果判定 {#expiry}

先确认周期已结束，再获取该产品要求的价格依据。期间触碰与收盘比较分别处理；价格缺失或延迟应进入既定异常流程，不能随意使用“当前最新价”代替应结算时点价格。

## 收益结算与入账 {#settle}

按确定的规则计算输赢、返还和费用，记录结算依据，再完成对应账务动作与状态更新。结算重试必须识别已完成入账，不能因任务重复执行再次派发。

触碰版本已检查到周期记录更新、交割中状态和逐订单结算方法；本文不把其事务实现直接推广到其他期权版本。
