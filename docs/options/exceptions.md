# 行情与异常处理

<div class="doc-lead">周期价格、产品规则和资金事实共同决定可复核的结算。</div>

## 行情与推送 {#market}

行情需要携带时间和产品上下文。客户端展示价、用户购买参考价与周期结算价可能承担不同用途，文档应明确各自来源。

## 异常与一致性 {#exceptions}

| 场景 | 应保留的处理依据 |
| --- | --- |
| 截止边界下单 | 服务端受理时间、周期及窗口规则 |
| 周期价格缺失 | 缺失原因、补取来源与处理记录 |
| 结算任务重复 | 订单结算标识与已入账事实 |
| 产品参数变更 | 原订单采用的参数版本 |
| 退款或退单 | 业务原因、原扣款与退还流水 |

异常期间不要通过临时改变收益率或历史参考价让账目“看起来正常”。修复必须可解释，并能够重新计算验证。
