# 产品与交易规则

<div class="doc-lead">结算规则必须在下单时明确，并能在事后复核。</div>

## 方向与期限 {#direction}

已检查的版本包含看涨、看跌、看平等结果定义，触碰版本还使用方向阈值及周期高低价。可选择方向、周期起止与可购买窗口应按产品分别列出。

## 下单条件与限额 {#limits}

下单需要检查账户、币种、金额范围、周期状态及产品是否开放。截止时间应基于服务端权威时间；客户端倒计时只用于展示，不能作为受理依据。

## 结果与收益规则 {#result}

到期比较开收盘、期间触碰阈值和其他判定方式是不同产品规则。尤其“到期价格没超过阈值”不能证明“期间从未触碰阈值”。

演算示例：假设投入 100 USDT，赢时净收益率 80%，规则约定返本金，则赢时总入账 180 USDT。若输时不返本金则入账为 0。此处仅解释本金、净收益与总返还的区别，不代表本项目所有期权产品的固定收益规则。
