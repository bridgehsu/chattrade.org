# 交易规则

<div class="doc-lead">先明确开平仓语义、价格依据和费用口径。</div>

## 开仓、平仓与方向 {#direction}

买卖方向与开平仓用途不是同一个维度。买入可以建立多仓，也可以用于平掉空仓。平仓量应考虑已占用的可平数量，防止多笔平仓订单重复使用同一持仓。

## 杠杆与保证金 {#margin}

教学示例：线性合约名义价值 3,000 USDT、杠杆 3 倍时，简单初始保证金约为 1,000 USDT，尚未计费用与风险参数。实际保证金需求还取决于产品、风险限额和仓位档位。

## 价格、限额与费用 {#fees}

最新成交价、指数价和标记价格具有不同用途。用于盈亏展示、强平和成交的价格依据必须分别说明。资金费仅适用于有该机制的产品，不能等同于借币利息，也不能默认为所有合约都收取。
