# 行情与异常处理

<div class="doc-lead">价格来源失效和交易处理失败需要不同的处置策略。</div>

## 合约价格体系 {#prices}

对每个产品明确最新价、指数价与风险参考价的来源、更新频率和异常条件。外部价格接入应检查时间戳、异常跳变和来源中断，不能把过期价格当作实时价格继续使用。

## 异常与一致性 {#exceptions}

重复平仓需要防止超出可平数量；重复清算需要防止多扣保证金或多记盈亏。风险计算、持仓变化和账户变化应共享可追踪的业务关联。

价格源失效时，应采用预先定义的暂停、降级或人工处理规则。未确认事实前，不应随意补价格、调整历史成交或直接修改用户盈亏。
