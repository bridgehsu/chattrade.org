# 接口约定与鉴权

<div class="doc-lead">接口文档首先需要解释身份、结果和重试语义。</div>

## 文档范围

本轮文档聚焦设计与业务流程，不列出尚未逐项核实的 HTTP 路径、签名算法和响应字段。后续接口清单应从实际接入服务整理，避免编造看似可用的 API。

## 必须说明的协议项

| 项目 | 应明确的内容 |
| --- | --- |
| 身份 | 用户会话、后台身份或开放接口凭证 |
| 范围 | 商户、账户、产品与资源归属 |
| 数值 | 金额、价格、数量精度与时间单位 |
| 结果 | 请求受理、处理中、最终完成的区别 |
| 重试 | 是否可重试、使用何种业务标识查询 |

## 鉴权与权限

鉴权确认调用者身份，权限检查确认其能操作目标资源。创建订单、提现、资产调整与普通行情查询应拥有不同的授权要求。
