# 邀请关系与奖励流程

<div class="doc-lead">把关系归属、奖励计算与实际发放分开。</div>

## 关系与奖励设计

工程中 coinex-user-relation 与 coinex-raward 分别可见用户关系和奖励相关定义。关系树只提供归属信息，奖励仍取决于活动、业务事实和适用规则。

## 计算与发放流程

<Flow :steps='["确认业务事实","确定关系与规则版本","计算应得奖励","检查资格及重复","执行发放","记录流水和发放结果"]' />

手续费返还、邀请奖励和活动奖金具有不同计费基础。文档应说明以成交额、实际费用还是其他指标计算，以及退款、撤销或无效行为如何处理。

## 异常处理

任务重复运行不应重复发奖。关系变更、规则调整与补发都需要保留依据，避免用当前关系重新解释过去奖励。
