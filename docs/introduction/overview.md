# 项目概述

<div class="doc-lead">理解 TGEX 文档的目标、业务范围与阅读方式。</div>

## 文档面向谁

本网站面向希望学习数字资产交易所设计的产品、研发与技术运营人员。内容从业务规则出发，解释服务职责、数据关系和关键流程，不逐行讲解源码。

TGEX 是这套文档站的名称，业务模块依据 Coinex 工程梳理。文档覆盖现货、合约、期权、钱包、OTC，以及商户管理、量化、运营与公共服务。

## 内容如何区分

| 内容类型 | 阅读方式 |
| --- | --- |
| 工程事实 | 已检查的模块结构、订单枚举、撮合组件等事实 |
| 业务流程抽象 | 为理解模块协作整理的流程，不等于精确的跨服务事务边界 |
| 设计建议 | 幂等、补偿、权限隔离、监控等应满足的设计目标，不宣称现有部署已全部实现 |
| 演算示例 | 价格、费率、限额均为教学假设，不代表平台实时参数 |

## 版本边界

工程内保留了多个期权实现及配套行情模块。模块存在不代表正在运行；具体启用版本、生产参数和部署拓扑需要结合运行环境确认。涉及差异的内容在对应业务章节说明。
