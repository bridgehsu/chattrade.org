# 常见故障排查

<div class="doc-lead">沿业务标识定位失败发生在哪一层。</div>

| 现象 | 优先检查 |
| --- | --- |
| 页面能打开但无法下单 | 接口代理、身份、交易状态与业务服务依赖 |
| 下单超时 | 原请求是否受理、撮合结果和账户占用 |
| 委托一直不成交 | 限价条件、对手流动性、撮合状态及外部路径 |
| 撤单后仍有冻结 | 撤销是否生效、剩余量与解冻处理结果 |
| 充值未到账 | 网络与地址、链上确认、监听记录和账务结果 |
| 提现长时间处理中 | 审核、发送记录、链上状态及余额费用 |
| 期权未结算 | 周期状态、结算价格、任务进度和入账事实 |
| 行情停止 | 上游连接、数据时间戳、行情加工与推送连接 |

## 排查记录

记录时间范围、商户、用户、订单或链上交易标识，以及已确认和未确认的事实。先查询再修复，避免重复下单、重复结算或直接调整余额掩盖问题。
