# 部署架构与服务配置

<div class="doc-lead">部署拓扑应对应实际依赖、数据边界和恢复要求。</div>

## 环境依赖 {#dependencies}

按服务列出数据库、Redis、配置中心、注册发现、MQ、搜索和链节点依赖。并非每个服务都需要所有组件，不应把完整基础设施当作所有学习场景的最低要求。

## 部署与启动顺序 {#startup}

工程中存在 devops 与相关部署目录，但当前文档未验证生产拓扑，不提供可以直接覆盖线上环境的一键部署指令。

## 配置管理 {#configuration}

分离环境配置与业务参数。发布时记录服务版本、参数变更、依赖变化和回滚方式。数据库结构变化与消息协议变化需要评估新旧服务兼容性。
