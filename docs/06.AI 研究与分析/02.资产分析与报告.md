# 资产分析与报告

<div class="doc-lead">从打开分析页到阅读报告的业务路径。</div>

## 桌面端路径

1. 进入 `/ai-asset-analysis`。
2. 加载情绪、指数、热力图、日历、机会与自选等市场上下文（首访较重，页面可 keepAlive）。
3. 发起分析或 Copilot 对话，等待后端返回。
4. 将结论用于策略构思，或打开公开报告页分享。

公开报告路由用于只读分享，不自动授予交易权限。

## 手机端路径

AI Hub（`/ai`）与 `/ai-analysis`、历史页构成轻量路径。适合查看结论与继续追问，复杂研报排版与多面板研究仍以桌面端为主。

## 异常

| 现象 | 处理 |
| --- | --- |
| 长时间无响应 | 检查代理与后端；超时后查任务/历史是否已生成 |
| 401 | 重新登录，勿静默重放分析请求 |
| 内容为空 | 区分“模型失败”与“标的无数据”，避免当成成功报告 |
