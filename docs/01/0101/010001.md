# 环境准备

<div class="doc-lead">建立隔离的学习环境，识别每个服务真实需要的依赖。</div>

## 环境组成

后端工程说明以 Java 8 和 Maven 为基础，但启动某个服务之前仍需检查它自己的构建配置。前端工程各自管理 Node.js 依赖，不能用后端版本推断前端环境。

## 准备顺序

1. 确定要学习的业务及对应服务版本。
2. 准备隔离数据库、Redis、配置中心和服务发现环境。
3. 按目标服务配置确认是否需要 MQ、搜索服务或链节点。
4. 使用测试账户和模拟资产完成业务验证。

## 环境边界

学习环境应使用自己的域名、数据库和消息主题。外部行情可以选择测试接入；链上转账应使用测试网络或隔离驱动。文档不提供已有环境的账号、密钥、内部地址和验证码。
