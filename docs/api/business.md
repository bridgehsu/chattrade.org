# 业务接口与错误处理

<div class="doc-lead">按业务动作描述输入、结果和状态查询方式。</div>

## 用户与资产接口 {#account}

注册登录关注身份与会话；资产查询关注账户、币种和余额口径；划转关注来源、目标、金额、业务编号与最终状态。

## 交易业务接口 {#trading}

下单需注明产品、方向、类型、价格与数量规则；撤单需注明可撤条件与并发语义；订单和成交查询应分开。合约需增加开平仓和持仓语义，期权需增加周期与产品规则。

## 行情与 WebSocket {#websocket}

协议应描述订阅主题、交易产品标识、快照与增量、时间戳、心跳及重连策略。不得假定客户端收到每一条推送。

## 错误码 {#errors}

区分参数不合法、未授权、业务拒绝、请求处理中和内部异常。错误文案不能代替业务结果查询，尤其是在网络超时和资金相关操作中。
