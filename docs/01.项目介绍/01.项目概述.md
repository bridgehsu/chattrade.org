# 项目概述

<div class="doc-lead">理解 ChatTrade 工作区文档的目标、工程边界与阅读方式。</div>

## 文档面向谁

本知识库面向维护与使用 **chattrade-workspace** 的产品、研发与运营人员。内容解释工作区内各工程的职责、关键流程与接入约定，不展开无关产品的交易所撮合源码。

ChatTrade 在本工作区中定位为 **AI 量化交易操作系统**：把行情研究、策略编写、回测、自动执行、券商/交易所账户与运营能力放在同一套系统里。站点域名为 [chattrade.org](https://chattrade.org)。

## 工作区工程

| 工程 | 定位 |
| --- | --- |
| `chattrade.org` | 本知识库（VitePress 文档站） |
| `chattrade-web` | 桌面端 Web 客户端（Vue 2.7） |
| `chattrade-mobile` | 手机端 / H5 / Capacitor 客户端（Vue 3） |

两端共用同一套后端 API（默认经 `/api` 反向代理）。本仓库**不包含**独立后端源码；后端接口语义以客户端已核实的调用为准。

## 内容边界

| 包含 | 不包含 |
| --- | --- |
| 工作区工程结构、本地启动、部署与排障 | tgex.net / 第三方交易所撮合引擎手册 |
| AI 研究、策略、回测、交易执行与券商账户 | 虚构尚未在工程中出现的接口路径 |
| 客户端鉴权、代理与容器配置约定 | 生产密钥、真实账号与内部地址 |

## 版本说明

客户端版本号以各工程 `package.json` 为准。功能是否启用取决于后端配置与部署环境，模块存在于前端路由中不代表线上一定开放。
