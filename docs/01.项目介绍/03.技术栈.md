# 技术栈

<div class="doc-lead">按工程理解 ChatTrade 工作区使用的技术组成。</div>

## 工作区技术组成

| 工程 | 主要技术 |
| --- | --- |
| chattrade-web | Vue 2.7、Vite 5、Ant Design Vue、Vue Router、Vuex、ECharts / KLineChart |
| chattrade-mobile | Vue 3、Vite、Vant、Pinia、Capacitor（H5 / Android / iOS） |
| chattrade.org | VitePress 1.6、Vue 3 |

包管理：桌面端使用 **pnpm**（以 `pnpm-lock.yaml` 为准）；手机端使用 **npm**；文档站使用 **npm**。

## 接入与运行时

| 层次 | 说明 |
| --- | --- |
| 浏览器 / App | 静态资源由 Vite 开发服务或 Nginx 提供 |
| API 代理 | 开发与生产均将 `/api/*` 转到后端，默认 `http://127.0.0.1:5000` |
| 后端 | 工作区外的 API 服务；前端通过 REST 调用策略、回测、交易、鉴权等接口 |
| 长任务 | AI 分析、回测等请求在客户端配置更长超时，不等于业务已完成 |

## 选型边界

前端状态（Vuex / Pinia、本地 Token）只服务展示与会话，不能当作资金或成交权威数据。策略草稿、回测报告与实盘成交是不同阶段，技术组件再相似也不能混为一谈。
