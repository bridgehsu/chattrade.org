# 文档阅读指南

<div class="doc-lead">按工作区工程顺序建立 ChatTrade 认知。</div>

## 推荐学习路线

1. 阅读[项目概述](/pages/0101)与[功能全景](/pages/0102)，弄清工作区边界。
2. 按[环境准备](/pages/0201)与[本地启动](/pages/0203)跑通 web 或 mobile。
3. 阅读[整体架构](/pages/0301)，理解客户端、代理与后端的关系。
4. 按需深入 AI 研究、策略回测、交易券商、指标与用户计费章节。
5. 部署前阅读[部署架构](/pages/1201)与[故障排查](/pages/1202)。

## 每篇文档怎样读

先看该能力对应哪个工程与路由，再看输入、输出和失败时如何查询。流程图表示业务先后，不保证同一次 HTTP 请求内完成全部副作用。

## 贯穿原则

- 页面能打开 ≠ API 已就绪。
- 回测结果 ≠ 实盘收益。
- 外部券商成交回执 ≠ 本地账户快照已更新。
- 超时后先查业务状态，再决定是否重试。
