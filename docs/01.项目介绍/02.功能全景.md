# 功能全景

<div class="doc-lead">从研究到执行，认识 ChatTrade 工作区的能力地图。</div>

## 核心能力

| 能力域 | 主要职责 | 工程入口 |
| --- | --- | --- |
| AI 研究 | 资产分析、Copilot、研究报告 | `chattrade-web` → AI 资产分析；`chattrade-mobile` → AI Hub |
| 策略 | 策略中心、Strategy IDE、脚本源 | `/strategy-center`、`/strategy-ide` |
| 回测 | 回测运行、历史、因子研究 | `/backtest-center` |
| 执行 | 交易机器人、执行器、闪电交易 | 策略执行相关页、`/api/quick-trade/*` |
| 券商账户 | IBKR / Alpaca 等账户连接 | `/broker-accounts` |
| 指标 | Indicator IDE、社区市场 | `/indicator-ide`、`/indicator-community` |
| 账户运营 | 登录、个人中心、计费、后台 | `/profile`、`/billing`、管理路由 |

## 客户端分工

| 客户端 | 适合场景 |
| --- | --- |
| chattrade-web | 完整工作台：研究、写策略、回测、管理账户与运营 |
| chattrade-mobile | 随身查看：AI、策略/机器人、行情图表、闪电交易、个人设置 |

两端不是两套系统，而是同一后端上的不同界面。详细路由见[桌面端](/pages/0401)与[手机端](/pages/0501)。

## 支撑能力

Agent Token、AI Skills、用户管理、品牌与系统设置等后台能力位于桌面端管理菜单。它们服务实例运营，不改变「研究 → 策略 → 执行 → 账户」主链路。
