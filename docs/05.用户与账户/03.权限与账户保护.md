# 权限与账户保护

<div class="doc-lead">明确用户、商户管理员与平台管理员的操作范围。</div>

## 权限设计

权限由身份、角色、资源范围和操作类型共同决定。知道订单编号不代表可以查询订单；拥有某个页面菜单也不等于拥有资金操作权限。

## 账户保护流程

<Flow :steps='["发现异常行为","限制敏感操作","验证账户归属","记录处理与审核","恢复对应权限"]' />

冻结登录、禁止交易、禁止提现是不同限制，应注明各自影响范围。强制退出会话不应被误认为已撤销全部委托。

## 审计要求

敏感操作应保留操作者、目标对象、商户范围、时间、原因和结果。日志中避免记录明文密码、验证码、完整密钥或可复用会话信息。
