# 资产体系与余额设计

<div class="doc-lead">以账户、余额和业务流水建立资金的解释链。</div>

## 账户分类 {#accounts}

工程中可见现货、OTC、期权等业务账户相关实现。账户划分用于隔离不同业务的资金占用和结算规则，展示时应说明当前余额属于哪个账户。

## 可用与冻结 {#balances}

教学模型中，总额 = 可用余额 + 冻结余额。冻结表示资金仍属于用户，但已被某个订单或提现占用。冻结不是已经支付，解冻也不是新增收益。

合约还需要权益、保证金与未实现盈亏等口径，不能直接套用简单现货余额公式。

## 流水 {#journal}

流水应能关联业务编号、账户、币种、变动类型和变动金额。同一资金动作重试时，应识别既有处理结果，而不是创建第二笔无关记录。
