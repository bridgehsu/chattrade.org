# 整体架构

<div class="doc-lead">ChatTrade 由客户端、API 接入与后端业务能力组成。</div>

## 分层示意

<Flow :steps='["chattrade-web / mobile","同源 /api 代理","鉴权与业务 API","策略 · 回测 · 交易 · 行情","账户与运营数据"]' />

工作区只直接维护客户端与文档。后端以 API 形式存在；前端不直连数据库，也不在浏览器里保存权威资金账本。

## 四类职责

| 职责 | 关注点 |
| --- | --- |
| 客户端 | 研究、策略、回测、交易与设置界面 |
| 接入 | 鉴权、代理、超时与错误展示 |
| 交易执行 | 策略信号、机器人、闪电下单、券商连接 |
| 运营 | 用户、计费、权限与实例配置 |

## 工程映射

| 层次 | 工程 |
| --- | --- |
| 文档 | chattrade.org |
| 桌面端 | chattrade-web |
| 手机端 | chattrade-mobile |
| 后端 API | 工作区外服务，经 `/api` 访问 |

订单、持仓与余额是否正确，应以 API 返回的业务事实为准；客户端缓存只服务交互流畅度。
