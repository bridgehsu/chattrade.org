# 客户端与 API 接入

<div class="doc-lead">理解开发代理、生产反代与请求身份如何传递。</div>

## 统一前缀

两端浏览器（或 WebView）只请求同源 `/api/*`。开发时由 Vite 代理，生产时由 Nginx 等把 `/api/` 转到 `BACKEND_URL`。

| 工程 | 开发代理配置 | 默认目标 |
| --- | --- | --- |
| chattrade-web | `VITE_DEV_PROXY_TARGET` | `http://127.0.0.1:5000` |
| chattrade-mobile | `VITE_DEV_API_TARGET` / `BACKEND_URL` | `http://127.0.0.1:5000` |

## 身份传递

桌面端请求封装会携带本地保存的访问 Token，并允许 Cookie。登录、拉取用户信息、登出对应 `/api/auth/login`、`/api/auth/info`、`/api/auth/logout` 等约定。401 时应清理本地凭证并回到登录，不重放写操作。

## 超时语义

普通业务请求默认较短超时；AI 分析、回测、生成类接口在客户端使用更长超时。超时只说明调用方没等到响应，必须用业务查询确认是否已受理。

## WebSocket

若行情或通知走 WebSocket，开发代理可开启 `ws` 转发。断线后应先拉快照再接增量，不要只用本地缓存做交易决策。
