# 数据与会话

<div class="doc-lead">分清本地会话、服务端业务数据与外部券商状态。</div>

## 三类数据

| 类型 | 存放位置 | 能否当作权威事实 |
| --- | --- | --- |
| 会话与偏好 | 浏览器本地存储 / App Preferences | 否，只证明“曾登录/偏好设置” |
| 业务实体 | 后端 API（策略、回测、用户等） | 是（以接口返回为准） |
| 外部券商状态 | IBKR / Alpaca 等外部系统 | 外部为准，需同步后再展示 |

## 会话生命周期

登录成功 → 客户端保存 Token → 后续 `/api` 请求带身份 → 登出或 401 → 清理本地状态。敏感操作失败时，应提示用户重新确认，而不是静默重试下单。

## 缓存与刷新

桌面端部分页面使用 `keepAlive` 避免重复拉行情。进入页面时若数据可能过期，应在激活钩子中刷新。缓存命中不等于最新成交或持仓。
