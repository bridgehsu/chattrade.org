# 核心设计

<div class="doc-lead">订单、周期、价格证据和结算事实应能相互关联。</div>

## 账户与资产 {#account}

期权下单资金与普通现货挂单占用未必相同。应明确购买时是扣款、冻结还是其他处理，结算时是发放收益、返还本金还是退单，不能统一称为解冻。

## 订单与周期状态 {#states}

已检查的 new-cxex 订单状态定义包含等待购买、购买中、等待交割、交割中、交割完成和退还；另有涨跌平结果相关定义。业务说明中应区分订单处理进度和结果方向。

## 价格依据与结算机制 {#price}

订单需关联交易产品、规则版本、购买时间、周期、参考价格和收益参数。周期记录应保存用于结果复核的价格依据。触碰产品还需要期间高低价或足够的路径证据。

结算状态与资金入账结果应可分别查询，避免界面显示“完成”而资产事实缺失。
