# 接口约定与鉴权

<div class="doc-lead">先约定身份、结果语义与重试规则，再讨论具体路径。</div>

## 已核实约定

| 约定 | 说明 |
| --- | --- |
| 前缀 | 浏览器只请求 `/api/*` |
| 代理 | 开发 Vite / 生产 Nginx 转到后端 |
| 鉴权 | Token + 可选 Cookie；401 需重登 |
| 超时 | 普通短、分析/回测长；超时≠失败定论 |

## 协议项清单

描述任一写接口时，应写清：身份范围、金额/数量精度、受理与终态区别、可查询业务编号、是否允许重试。

## 不在本文展开

后端内部实现、未在客户端出现的路径、生产密钥算法细节。需要完整 OpenAPI 时以服务端仓库为准。
