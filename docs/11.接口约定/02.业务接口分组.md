# 业务接口分组

<div class="doc-lead">按客户端已封装模块理解业务接口分组。</div>

## 分组一览

| 分组 | 代表前缀 | 用途 |
| --- | --- | --- |
| 鉴权 | `/api/auth/*` | 登录、用户信息、登出 |
| 策略 | `/api/strategies/*` | 策略、执行器、日志、通知 |
| 回测 | `/api/backtest/*` | 运行、历史、因子研究 |
| 闪电交易 | `/api/quick-trade/*` | 下单、余额、持仓、历史 |
| 券商 | `/api/ibkr/*`、`/api/alpaca/*` | 连接与交易查询 |
| 用户/计费 | `/api` 下 user、billing 等 | 账户运营 |

## 错误处理

区分参数错误、未授权、业务拒绝、处理中与内部异常。展示给用户的文案不能替代“查询最终状态”。资金与下单类失败后，先查再改。

## 版本兼容

前端多版本并存时，后端应保持旧字段可读或提供明确错误。文档站不保证与某个后端 git 提交逐字段同步，联调以实际响应为准。
