# 产品管理与审核流程

<div class="doc-lead">管理操作影响交易规则，应明确生效范围和审核依据。</div>

## 币种与交易产品管理 {#products}

创建币种、网络、交易对或衍生品时，应确认相关账户、行情、撮合和钱包是否具备对应能力。配置记录保存成功不等于业务链已就绪。

## 用户、订单与资金管理 {#management}

查询、限制、审核与资金调整是不同操作。订单查询应展示关联成交与资金记录，避免管理员仅凭单一状态判断结果。

## 关键操作与审核 {#approval}

<Flow :steps='["提交变更与原因","校验权限和影响范围","按规则审核","执行并记录结果","验证业务生效","保留审计记录"]' />

这是后台治理的设计建议。具体是否双人审核、是否支持回滚，应根据业务风险与已有实现说明，不能默认所有管理功能都有相同审批链。
