# 核心充提流程

<div class="doc-lead">分别追踪充值、提现和归集，避免混淆不同资金归属。</div>

## 充值监听与入账 {#deposit}

<Flow :steps='["扫描区块或交易","识别网络 / 币种 / 用户","记录待确认充值","达到确认要求","调用账务入账","核对并通知用户"]' />

充值入账前需核对地址、金额、代币与确认情况。补扫区块时可能再次发现同一笔交易，应使用原链上事件标识查询处理结果。

## 提现申请与审核 {#review}

验证账户、安全条件、网络、地址、金额和费用，建立提现记录并处理资金占用。审核通过只表示允许发送，不代表链上转账已成功。

## 提现发送与确认 {#withdraw}

<Flow :steps='["审核通过","构造并签名交易","广播并记录交易标识","跟踪链上结果","确认账务与订单状态","完成或进入异常处理"]' />

广播超时可能发生在交易已发送之后。重试前需查询交易和发送记录，不能直接生成第二笔付款。

## 资金归集 {#collection}

归集是平台链上地址之间的资金调度，通常不改变用户内部余额。归集任务需要记录来源、目标、网络费用和执行结果；代币归集还可能需要先准备网络手续费资产。
