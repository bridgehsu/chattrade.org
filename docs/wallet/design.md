# 核心设计

<div class="doc-lead">币种、网络、地址和链上交易必须共同标识资产。</div>

## 币种与网络 {#network}

同一币种不同网络分别配置驱动、精度、确认要求和转账费用。代币还需要对应合约地址。不能只用币种简称识别链上资产。

## 地址管理 {#address}

地址分配需要绑定用户、商户、币种和网络；需要 Memo 或 Tag 的网络还应记录附加标识。地址校验应在提现发起前完成，展示时清晰标注网络。

## 交易与确认数 {#confirmations}

交易被广播、节点可查询、进入区块、达到确认要求是不同阶段。链上交易唯一性有时需要网络、交易哈希和事件序号等组合，不能假定一个交易哈希只包含一笔充值。

## 钱包与内部账务 {#ledger}

钱包记录证明链上动作，账务记录证明用户权益变化。充值监听重试必须识别既有入账，提现重试必须先确认已有交易是否发送，避免重复付款。
