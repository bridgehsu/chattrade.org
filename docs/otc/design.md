# 商家、规则与核心设计

<div class="doc-lead">明确广告剩余额度、订单状态和托管资产之间的关系。</div>

## 商家与交易规则 {#merchant}

商家申请、可交易币种、法币、支付方式、单笔限额和时限共同定义交易条件。广告可见不等于用户一定符合所有购买要求。

## 广告与委托 {#advert}

广告描述可交易条件，订单描述一次具体交易。下单后需要处理广告可用数量及对应数字资产，防止多个订单超出可售额度。

## 订单状态 {#states}

教学流程可分待付款、待放币、完成、取消和申诉中等阶段；实际状态值与分支以订单模块为准。付款标记、收款确认和平台放币是不同事实。

## 冻结与释放 {#funds}

数字资产由订单占用并在完成或取消后处理。发生申诉时，应明确是否维持占用，以及由谁有权改变最终结果，避免普通超时任务释放正在争议中的资产。
