# 业务概述与系统架构

<div class="doc-lead">工程中的 OTC 包含商家、广告委托、订单及申诉相关能力。</div>

## 参与者

买方、卖方或商家、平台订单服务、账户服务和申诉处理人员共同参与。线下支付发生在平台内部币种划转之外，用户点击“已付款”不代表平台自动证明银行到账。

## 模块架构

coinex-otc 中可见委托、订单、商家申请、手续费、申诉和冻结移动相关服务。此处的 OTC 说明以这些流程为基础，不将其默认描述为机构大宗询价系统。
