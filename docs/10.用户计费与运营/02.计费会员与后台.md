# 计费会员与后台

<div class="doc-lead">会员、积分与管理功能支撑实例运营。</div>

## 计费

桌面端 `/billing` 与 `src/api/billing.js` 处理套餐、支付与额度相关流程。具体支付通道以部署配置为准；文档不描述未核实的第三方商户号。

## 后台

具备 admin 权限时可进入用户管理、AI Skills、系统设置等页面。后台变更影响全实例，应记录操作者与变更内容，并与普通交易权限隔离。

## 品牌与设置

品牌文案、主题与系统设置影响客户端展示，不改变撮合或券商侧成交规则。改品牌后需同步检查登录页、关于页与原生应用名称是否一致。
