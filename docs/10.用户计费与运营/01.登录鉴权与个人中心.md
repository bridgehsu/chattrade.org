# 登录鉴权与个人中心

<div class="doc-lead">建立会话、管理资料，并为敏感操作提供安全边界。</div>

## 登录

两端均通过 `/api/auth/*` 完成登录、拉取用户信息与登出。桌面端登录页与手机 `/login` 只是不同壳，会话语义一致：成功后保存 Token，失败或 401 时清理。

## 个人中心

`/profile` 聚合资料、通知、Agent Token 等能力。Agent Token 用于外部代理调用本实例 API，具备较高风险，签发时需提示限流与权限范围。

## 安全

修改安全设置、绑定交易所密钥等操作应二次确认。客户端不得在无会话时缓存可写操作队列自动重放。
