# 本地启动

<div class="doc-lead">分别启动文档站、桌面端与手机端开发服务。</div>

## 启动前

先保证后端 API 可访问。仅启动前端时，静态页可能打开，但登录与业务接口会失败。

## chattrade.org

```sh
cd chattrade.org
npm ci
npm run dev
```

默认本地地址：`http://127.0.0.1:5173/`。

## chattrade-web

```sh
cd chattrade-web
corepack enable
pnpm install
pnpm run serve
```

默认：`http://localhost:8000`。`/api` 代理到 `VITE_DEV_PROXY_TARGET` 或 `http://127.0.0.1:5000`。

## chattrade-mobile

```sh
cd chattrade-mobile
npm install
npm run dev
```

默认：`http://localhost:5173`。`/api` 代理到 `VITE_DEV_API_TARGET` / `BACKEND_URL` 或 `http://127.0.0.1:5000`。

## 启动后验证

| 检查项 | 通过标准 |
| --- | --- |
| 页面 | 登录页或主框架可打开 |
| 代理 | 浏览器网络面板中 `/api/...` 非连错主机 |
| 鉴权 | 可用测试账号登录并拉取用户信息 |
| 业务 | 至少一个只读接口（如用户信息 / 策略列表）返回成功 |

手机访问局域网内电脑时，把 `localhost` 换成电脑局域网 IP，并确认后端与 CORS / 代理允许该来源。
