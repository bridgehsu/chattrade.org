# 环境准备

<div class="doc-lead">准备运行 ChatTrade 客户端与文档站所需的本地环境。</div>

## 运行时要求

| 工程 | 建议环境 |
| --- | --- |
| chattrade-web | Node.js 22 LTS，pnpm 10.x（Corepack），后端 API 可达 |
| chattrade-mobile | Node.js 20.19+ / 22.12+，npm；原生构建另需 Android Studio / Xcode |
| chattrade.org | Node.js 22，npm |

不要把三个工程的包管理器混用，也不要用后端语言版本去推断前端 Node 版本。

## 准备顺序

1. 确认要启动的客户端（web / mobile / 两者）。
2. 启动或拿到可访问的后端 API（默认 `http://127.0.0.1:5000`）。
3. 安装对应工程依赖：web 用 `pnpm install`，mobile 用 `npm install`。
4. 如需改代理目标，设置 `VITE_DEV_PROXY_TARGET`（web）或 `VITE_DEV_API_TARGET` / `BACKEND_URL`（mobile）。

## 环境边界

学习与开发环境应使用自己的后端实例与测试账户。文档不提供已有环境的账号、密钥、验证码或生产域名凭据。
